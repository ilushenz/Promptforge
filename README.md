# PromptForge

Generate perfect AI image compositing prompts — free, instant, no backend.

Fill in a form, select 4 viewing angles, get 4 ready-to-paste prompts for Gemini or any AI image tool.

## Run locally

1. Open a terminal in this folder
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`

## Deploy for free

Run `npm run build`, then drag the `dist/` folder into [netlify.com/drop](https://app.netlify.com/drop). No account required.
